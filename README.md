A tiny stack virtual machine for make.fun's "Tiny Stack VM" bounty, $100 in USDC. One program answers all 40 instances of a set: 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input and output, and all ten traps with their exact exit codes — including the hard edge cases (wrapping multiply, INT_MIN / -1, unsigned division, shift masking, PUSH8 sign extension, step and output limits).

## Run it

```sh
node main.ts
```
